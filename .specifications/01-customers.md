# Customer Management

## Requirements

- Ability to add, edit, and delete customer records.
- Support soft delete functionality to allow recovery of deleted customers.
- Implement search functionality to find customers by name or email.
- A customer consists of the following fields:
  - First Name
  - Last Name
  - Email
  - Phone Number
  - Address
  - Company
  - Notes
- Create a main menu with one menu item labeled "Customers" that navigates to the customer management interface.

## Database

I want to be able to set the path for the SQLite database with an environment variable.
