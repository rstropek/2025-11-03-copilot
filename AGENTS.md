# CRM NG

## Overview

This project is a Customer Relationship Management (CRM) system implemented with the following technologies:

### Core Technologies

- **Next.js 16** - React framework for production with App Router
- **React 19** - UI library
- **TypeScript 5** - Type-safe JavaScript
- **Tailwind CSS 4** - Utility-first CSS framework

### Database & Validation

- **better-sqlite3 12** - Fast SQLite3 database driver
- **Zod 4** - TypeScript-first schema validation

### Development Tools

- **ESLint 9** - Code linting with Next.js config
- **PostCSS** - CSS processing with Tailwind integration
